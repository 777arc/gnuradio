# Project instructions

## WASM editor

- Whenever you change anything on the WASM side (e.g. `wasm/editor/`), always rebuild afterward (`cd wasm/editor && npm run build`) so `dist/` reflects the change. Don't consider the task done until the build succeeds.

## Git

- Never make commits, and never ask to. Leave all committing to the user. Don't worry about uncommitted changes in general.
